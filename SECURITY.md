# Zgłaszanie problemów bezpieczeństwa

Nie umieszczaj publicznie haseł, tokenów, zrzutów zawierających dane prywatne ani pełnych logów z adresami publicznymi. Dla problemów bezpieczeństwa otwórz zgłoszenie w repozytorium i poproś o bezpieczny kanał kontaktu. Repozytorium docelowe: https://github.com/blasz59150/foxess-tseries-over-tcp/issues

To repozytorium nie zawiera mechanizmu zdalnego sterowania falownikiem; opisuje odbiór telemetrii. Nie wystawiaj portu konwertera bezpośrednio do internetu.
